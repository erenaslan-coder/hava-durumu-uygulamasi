# Hava Durumu Uygulaması

Bu başlangıç projesi, yazılan şehir veya cihazın mevcut konumu için güncel sıcaklık, hava durumu, nem, rüzgâr hızı ve beş günlük tahmini gösterir. Son aranan şehirler tarayıcıda saklanır; sıcaklık Celsius veya Fahrenheit olarak görüntülenebilir.

## Çalıştırma

`index.html` dosyasına çift tıkla. Ardından şehir adını yazıp **Ara** butonuna bas.

Veriler Open-Meteo'nun ücretsiz, API anahtarı gerektirmeyen servisinden gelir. İnternet bağlantısı gereklidir.

## Öğreneceğin parçalar

- `index.html`: Sayfanın yapısı
- `style.css`: Sayfanın görünümü
- `script.js`: Butona basıldığında çalışan JavaScript ve internetten veri alma işlemi

## Küçük geliştirme fikirleri

1. Mevcut konumun şehir adını da göster.
2. Favori şehirler listesi oluştur.
3. Gün doğumu ve gün batımı bilgisi ekle.
